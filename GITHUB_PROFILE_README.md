## **📌 Selected Work**

### **🖥️ eLUXE3D — High-Precision 3D Scanning Software**

Re-architected a legacy C++ jewelry scanning product into a split-stack desktop platform: Electron/React UI + multithreaded native C++ compute (Open3D / PCL) for metrology and CAD export.

- Zero-copy **Node-API** bridge streaming and processing **5M+ point clouds** without event-loop stall
- Point-to-plane **ICP**, Poisson reconstruction, and **QEM** mesh decimation (~**90%** size reduction) while preserving high-curvature facets and 1:1 metric tolerances
- Production releases: 3D lasso ray-cast partitioning, optical FOV sync (30–80 mm), signed Windows binaries, AWS S3 OTA across **6 milestones**

**Stack:** `Electron` · `React` · `Three.js / WebGL` · `Node-API` · `C++` · `Open3D / PCL` · `AWS S3`

## **🏗️ How I Engineer**

I optimize for systems that stay shippable after the first release:

- Clear service and API boundaries
- Schemas and indexes designed for the queries you actually run
- Performance work backed by measurement (P95, memory, token cost)
- Concurrency treated as a first-class design problem — not a later patch
- AI used where it creates measurable leverage, with evals and guardrails
- Automate delivery (CI/CD, containers, OTA) so releases are boring
- Prefer simple architectures that can evolve over clever ones that can't
